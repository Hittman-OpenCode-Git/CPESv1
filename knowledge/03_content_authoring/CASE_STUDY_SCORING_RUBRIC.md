# CMA Part 1 Case Study Scoring Rubric

**Version:** 1.0
**Status:** Active
**Authority:** CASE_STUDY_GOLD_STANDARD.md

---

# Purpose

This rubric provides a standardized scoring framework for evaluating case study quality.

Every case study shall be scored against this rubric before production release.

The rubric is organized into five domains matching the Gold Standard:

- Scenario
- Exhibits
- Questions
- Explanations
- Psychometrics

Each criterion is scored 0, 1, or 2.

| Score | Meaning |
|-------|---------|
| 0 | Does not meet standard |
| 1 | Partially meets standard |
| 2 | Fully meets standard |

**Pass threshold:** 40/50 (80%)
**Gold Standard threshold:** 48/50 (96%)

---

# Domain 1: Scenario (10 points)

## 1.1 Business Narrative

| Score | Description |
|-------|-------------|
| 0 | Scenario is absent, generic, or uses placeholder text ("The company is preparing a budget") |
| 1 | Scenario names a company but does not establish a realistic business context or industry |
| 2 | Scenario names a specific company in a recognizable industry with a plausible business situation |

## 1.2 Named Stakeholders

| Score | Description |
|-------|-------------|
| 0 | No stakeholder is named or implied |
| 1 | A generic stakeholder is mentioned ("the CFO," "management") |
| 2 | A named or specifically titled stakeholder is identified with a clear role (e.g., "CFO Maria Chen," "the controller," "internal audit team") |

## 1.3 Business Pressure

| Score | Description |
|-------|-------------|
| 0 | No urgency, deadline, or consequence is present |
| 1 | A deadline or constraint is mentioned but vague ("before year-end") |
| 2 | A specific, measurable constraint creates tension (e.g., "bank requires $35,000 compensating balance," "before the month-end purchasing deadline") |

## 1.4 Explicit Deliverables

| Score | Description |
|-------|-------------|
| 0 | No deliverables are stated; the candidate must infer what to produce |
| 1 | A general deliverable is stated ("prepare a cash forecast") |
| 2 | The specific outputs are enumerated ("total collections, total disbursements, cash position before financing, and required borrowing") |

## 1.5 Decision Required

| Score | Description |
|-------|-------------|
| 0 | No decision is requested; the case is purely computational |
| 1 | A decision is implied but not explicitly connected to case facts |
| 2 | A specific decision is tied to a threshold or contingency in the scenario (e.g., "if the deficit exceeds $100,000, negotiate supplier terms") |

# Domain 2: Exhibits (10 points)

## 2.1 No Decorative Data

| Score | Description |
|-------|-------------|
| 0 | One or more exhibit rows are never referenced by any question |
| 1 | All rows are referenced, but data exists that could be removed without affecting any answer |
| 2 | Every row is consumed by at least one question; no extraneous data present |

## 2.2 Every Exhibit Referenced

| Score | Description |
|-------|-------------|
| 0 | One or more exhibits are not referenced by any question |
| 1 | All exhibits are referenced, but data from some exhibits is only tangentially used |
| 2 | All exhibits are referenced, and each exhibit provides essential data for at least one question |

## 2.3 Internal Consistency

| Score | Description |
|-------|-------------|
| 0 | Exhibit data conflicts internally (e.g., percentages do not sum to 100%) |
| 1 | Exhibit data is consistent but contains ambiguous formatting or missing context |
| 2 | All data is internally consistent, percentages sum correctly, and no ambiguity exists |

## 2.4 Realistic Formatting

| Score | Description |
|-------|-------------|
| 0 | Exhibits are plain text with no structure, or use placeholder content |
| 1 | Exhibits use tables but have unclear headers, inconsistent number formatting, or missing dollar signs |
| 2 | Exhibits use clean table format with clear headers, consistent number formatting, and appropriate labeling |

## 2.5 Data Sufficiency

| Score | Description |
|-------|-------------|
| 0 | A question requires data not present in any exhibit; the candidate must guess |
| 1 | All required data is present but scattered or difficult to locate |
| 2 | All data needed to answer every question is present and logically organized across exhibits |

# Domain 3: Questions (10 points)

## 3.1 Progressive Difficulty

| Score | Description |
|-------|-------------|
| 0 | All questions test the same cognitive level (e.g., all recall) |
| 1 | Questions vary but do not follow a clear progression |
| 2 | Questions follow the 4-level progression: Apply → Analyze → Evaluate → Synthesize |

## 3.2 Mixed Question Types

| Score | Description |
|-------|-------------|
| 0 | Only one question type is used (e.g., all select) |
| 1 | Two question types are used |
| 2 | Three or more question types are used (numeric, select, multi-select, fill, match) |

## 3.3 Judgment Before Recall

| Score | Description |
|-------|-------------|
| 0 | The case relies entirely on recall or formula application |
| 1 | One question requires judgment or evaluation |
| 2 | At least two questions require judgment, evaluation, or synthesis (multi-select or match) |

## 3.4 Accounting Reasoning

| Score | Description |
|-------|-------------|
| 0 | Questions test arithmetic only, with no accounting concept required |
| 1 | Questions require selecting the correct formula but do not test conceptual understanding |
| 2 | Questions require the candidate to identify the correct accounting principle before calculating or selecting an answer |

## 3.5 Business Decisions

| Score | Description |
|-------|-------------|
| 0 | All questions are computational with no business context |
| 1 | Questions reference the business scenario but do not require a business decision |
| 2 | At least one question requires the candidate to make or evaluate a business decision based on the case facts |

# Domain 4: Explanations (10 points)

## 4.1 Formula

| Score | Description |
|-------|-------------|
| 0 | No formula is shown; only the correct answer is stated |
| 1 | A formula is referenced but without variable substitution |
| 2 | The formula is shown with actual numbers substituted (e.g., "$600,000 x 20% = $120,000") |

## 4.2 Principle

| Score | Description |
|-------|-------------|
| 0 | No accounting principle is stated |
| 1 | A principle is mentioned but not explained |
| 2 | The governing accounting principle is clearly stated and connected to the answer |

## 4.3 Why Correct

| Score | Description |
|-------|-------------|
| 0 | No explanation of why the answer is correct |
| 1 | A partial explanation is given |
| 2 | A complete explanation traces the reasoning from principle to calculation to answer |

## 4.4 Why Incorrect

| Score | Description |
|-------|-------------|
| 0 | No incorrect alternatives are addressed |
| 1 | One or two distractors are briefly addressed |
| 2 | Multi-select explanations address each choice individually; select explanations address significant distractors |

## 4.5 Common Trap

| Score | Description |
|-------|-------------|
| 0 | No common trap is identified |
| 1 | A common trap is implied but not explicitly named |
| 2 | At least one explanation explicitly names a common error (e.g., "A common error is to apply collection percentages to total sales instead of credit sales") |

---

# Domain 5: Psychometrics (10 points)

## 5.1 No Obvious Distractors

| Score | Description |
|-------|-------------|
| 0 | Distractors include absurd choices that any candidate would immediately reject |
| 1 | Distractors are plausible but one is clearly weaker than the others |
| 2 | All distractors represent realistic accounting mistakes or common misconceptions |

## 5.2 Tests Understanding

| Score | Description |
|-------|-------------|
| 0 | Questions can be answered correctly by pattern-matching or eliminating obviously wrong answers |
| 1 | Some questions require understanding, but others can be gamed |
| 2 | All questions require genuine understanding of the accounting concept |

## 5.3 Tests Judgment

| Score | Description |
|-------|-------------|
| 0 | All questions test recall or formula application only |
| 1 | One question requires judgment or evaluation |
| 2 | The multi-select or match question requires the candidate to evaluate statements or map concepts, not just calculate |

## 5.4 Appropriate Difficulty

| Score | Description |
|-------|-------------|
| 0 | Case is too easy or too difficult for the target audience |
| 1 | Difficulty is appropriate for most questions but one is misaligned |
| 2 | Difficulty is appropriate for the domain and estimated time; progression is smooth |

## 5.5 Time Appropriateness

| Score | Description |
|-------|-------------|
| 0 | Estimated time is clearly unrealistic for the number or difficulty of items |
| 1 | Estimated time is reasonable but tight or generous |
| 2 | Estimated time is appropriate; the average candidate can complete all items within the estimate |

# Scoring Summary

| Domain | Max Points |
|--------|-----------|
| 1. Scenario | 10 |
| 2. Exhibits | 10 |
| 3. Questions | 10 |
| 4. Explanations | 10 |
| 5. Psychometrics | 10 |
| **Total** | **50** |

| Level | Score | Action |
|-------|-------|--------|
| Gold Standard | 48–50 | Approved for production; designated as reference implementation |
| Production Ready | 40–47 | Approved for production after minor fixes |
| Needs Revision | 30–39 | Revise and resubmit; identify specific gaps |
| Reject | Below 30 | Restructure case from scratch |

## Passing (41/50)

A well-constructed single-topic case with minor gaps.

| Criterion | Score | Typical Gap |
|-----------|-------|-------------|
| Scenario | 8/10 | Stakeholder named but no named person |
| Exhibits | 9/10 | One decorative row |
| Questions | 8/10 | Missing one question type |
| Explanations | 8/10 | No common trap called out |
| Psychometrics | 8/10 | One weaker distractor |
| **Total** | **41/50** | |

## Needs Revision (32/50)

A case with placeholder remnants or significant gaps.

| Criterion | Score | Typical Gap |
|-----------|-------|-------------|
| Scenario | 5/10 | Generic company, no pressure |
| Exhibits | 6/10 | Text-based exhibits, decorative data |
| Questions | 7/10 | All same type or level |
| Explanations | 7/10 | Minimal explanations |
| Psychometrics | 7/10 | Distractors are generic |
| **Total** | **32/50** | |

# Usage

## During Authoring

Score the case against this rubric after the first draft. Identify gaps and revise before submitting for review.

## During Review

The reviewer scores each criterion independently. If the reviewer score differs from the author score by more than 2 points on any criterion, the case returns to the author with an explanation of the discrepancy.

## During Production Gate

A case must score at least 40 to pass the production gate. A case scoring 48 or higher may be designated as a domain reference implementation.
