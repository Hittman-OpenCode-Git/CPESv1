# S850 — Cognitive Level Certification: Evaluate vs. Analyze

## 1. Classification Standard

| Cognitive Level | What It Tests | Question Format |
|----------------|---------------|-----------------|
| **Analyze** | Break down information, identify patterns, explain relationships | "What caused this variance?" "Compare these two approaches" "Which factor explains this outcome?" |
| **Evaluate** | Make judgments among competing valid options, apply criteria under constraints | "Which recommendation should management implement?" "Given these trade-offs, what is the best course of action?" |

## 2. P1-E-R10 Classification Evidence

| Dimension | Evidence |
|-----------|----------|
| **Judgment required** | Candidate must choose among 4 valid recommendations, each with strengths and weaknesses |
| **Trade-off analysis** | Budget constraint ($5,000); each option evaluated for cost-feasibility |
| **Competing valid options** | All 4 distractors are plausible actions — none is obviously wrong |
| **Criteria-based decision** | Cost-effectiveness, risk-reduction magnitude, match to control gap |
| **Recommendation format** | Stem asks "which recommendation should the owner implement?" |

**Verdict: CONFIRMED AS EVALUATE.** The item tests judgment under constraints, not identification of control concepts.

## 3. Future Evaluate vs. Analyze Guard

Any item labeled "Evaluate" must:
- Require judgment among competing valid alternatives
- Include constraints that make choices non-obvious
- Use recommendation/decision question format
- Justify the correct answer with trade-off analysis, not just factual correctness

Items that only identify, classify, or explain without trade-offs are Analyze, not Evaluate.

## 4. Pipeline Feasibility

The Evaluate upgrade requires approximately 1.8x more effort than Analyze (5.3 min vs 2.7 min measured) because:
- Stem must be reformatted from identification to recommendation
- Choices must be rewritten as competing actions, not concept labels
- EC must include trade-off analysis with constraint assessment

The pipeline handles both tiers, but Evaluate authoring cannot be fully automated — it requires substantive judgment in distractor design.
