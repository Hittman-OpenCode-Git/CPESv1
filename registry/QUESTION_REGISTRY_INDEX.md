## Search Keys

The following fields are indexed for search across all partitioned registries:

- **QuestionID** — e.g., `P1-E-R01`, `P1B-E-076`, `CBQ5-E1-Q1`
- **Blueprint Domain** — A/B/C/D/E/F per CMA Part 1 CSO
- **Topic/MicroTopic** — Full topic descriptor string
- **Learning Objective** — LOSTag (e.g., `E.1.d Risk Assessment`)
- **Difficulty** — Easy, Moderate-Easy, Moderate, Difficult
- **CognitiveLevel** — Remember, Understand, Apply, Analyze
- **Source Pack** — pack_a through pack_e or scored_cases1–5
- **Case** — Case bank name for CBQ items

## Usage for Pre-Authoring Duplicate Check

Before authoring any new item (S314+, all 800-Series sessions):

1. Search `QUESTION_REGISTRY_INDEX.md` for the target QID to confirm no collision
2. Search the relevant domain registry for topic overlap
3. Search the relevant pack registry for content proximity
4. Record `DUPLICATE_PREVENTION_PASS` before entering Gate 0 (Draft)

**Gate 0 — Duplicate Prevention** is mandatory for all 800-Series authoring sessions.
