## 6. Reconciliation — DL-007 Unique-QID Discrepancy (1,011 vs. 882)

### 6.1 Discrepancy Identified

`DEFECT_LIBRARY.md` DL-013 reports **1,011** unique QuestionIDs across Packs A, C, D. This sweep reports **882** at the same 2,587 occurrence count. Both cannot be correct. The reconciliation below resolves this.

### 6.2 Four Independent Counting Methods

| Method | Approach | Boundary-Aware? | Result |
|--------|----------|----------------|--------|
| M1 — JS eval parse | `eval()` the complete `MCQ_BANK_X` array, iterate items checking all `ExplanationWrong*` fields | Yes (JS object structure) | **882** |
| M2 — Line-window scan | PowerShell `Select-String` for template pattern, backward-search 50 lines for nearest `"QuestionID"` field | No (proximity-based) | **882** |
| M3 — Brace-matched extraction | Depth-aware `{`/`}` brace matching to extract complete JSON objects from source text, check for template text within each object boundary | Yes (brace-delimited) | **882** |
| M4 — QID→template boundary verification | For each QID→template association, verify the template text position falls within the same `{...}` block as the QID. Counts valid vs. invalid (cross-object) associations. | Yes (brace-range check) | **882** (295/295, 1146/1146, 1146/1146 valid; 0 invalid) |

All four methods converge at **882 unique QIDs** (Pack A: 118, Pack C: 382, Pack D: 382). Zero cross-object invalid associations in Method 4.

### 6.3 Root Cause of the 1,011 Error

The 1,011 figure in `DEFECT_LIBRARY.md` DL-013 is **erroneous** — it overcounts by 129 QIDs (14.6%).

**Most likely cause:** the same class of boundary-unaware scanning error that produced the 9-Certified-QID false positive earlier in Session 2 (documented in the DL-013 entry itself). A window-based scan can misattribute QIDs from adjacent template-free items to template-containing items when using a forward-search or overly wide window.

Specifically:
- Template-containing items appear in clone groups (consecutive QIDs with identical template text)
- A window-based forward scan that finds QID line first, then looks for template text, will associate the template text from the next consecutive item with the current QID if the window extends past the object boundary
- With average ~3 template hits per QID and 882 actual QIDs, a forward-scan overcount of ~129 QIDs represents roughly one extra QID counted per ~7 actual QIDs — consistent with clone-group adjacency effects

**Total occurrences (2,587) are correct and undisputed.** Only the unique-QID count is affected.

### 6.4 Boundary-Aware Verification Confirmed

All four methods in this sweep are boundary-aware or were verified against a boundary-aware method:
- M1 and M3 are boundary-aware by construction (JS object parsing and brace-delimited extraction)
- M2 was cross-validated against M1/M3 and produced identical results
- M4 explicitly verified zero cross-object invalid associations
