## 4. Feature Decision Matrix

### Should ADD (improves learning without harming realism)
| Feature | Reason |
|---------|--------|
| A/B/C/D key selection | CMA exam behavior, muscle memory |
| Strikethrough | CMA exam behavior, test strategy |
| Review Flagged Only (pre-submit) | CMA exam behavior |
| Confidence Dashboard | Metacognition, already data-rich |
| Domain Readiness Visualization | May already computes this |
| Session History Analytics | Trend analysis, motivation |
| Recovery Sprint Results Card | Compare source vs sprint performance |
| Export/Print Results | Learner expectation |
| Chart Visualizations | Text-heavy dashboard needs visual lift |
| Submit Confirmation Dialog | Safety, CMA has this |
| SOCROTIC May Mode Activation | Already built, adds depth |
| All Wrong Choices pre-expanded | Default-open for better learning |
| Setup Presets ("Focus A", "Weakest") | Reduces configuration friction |

### Should NOT ADD (damages CMA simulation)
| Feature | Why NOT |
|---------|---------|
| Real-time answer correction during timed exam | CMA doesn't show answers during exam |
| Section-level timers | CMA has one global timer |
| Negative marking for wrong answers | CMA doesn't penalize wrong answers |
| Leaderboard / peer comparison | Not a CMA exam feature; adds anxiety |
| Music / ambient sounds | Wouldn't exist at Prometric |
| Spaced-repetition question re-ordering during exam | CMA order is fixed |
| "Undo Submit" after completing | CMA doesn't allow this |
| Auto-progression after answering | CMA requires manual navigation |
| Bookmarks / "save for later" beyond flagging | Flagging IS the CMA mechanism |
| Social features (share score, compete) | Detracts from serious study |
