## 4. Script Architecture

### 4.1 Input Parsing

**Method:** Boundary-aware block extraction using `QuestionID` / `CaseID` markers.

For each `scored_cases*.js` file:
1. Read entire file as string
2. Locate each `"ItemID": "CBQ..."` marker
3. Extract the enclosing `{ ... }` object using string-aware brace matching
4. `JSON.parse()` the extracted block

**String-awareness is mandatory** (per DL-020 lesson). Brackets inside string values must not affect the brace counter.

### 4.2 Item Identification

Each parsed item must match ALL of:
- `item.Type === "match"`
- `item.ItemID` is NOT in the Wave 1 exclusion list
- `item.Correct` is an object with ≥1 key
- `item.LeftItems` is an array
- `item.RightItems` is an array

### 4.3 Derangement Shuffle Algorithm

```
function shuffleRightItems(item):
    let leftItems = item.LeftItems
    let rightItems = item.RightItems.slice()  // shallow copy
    let correct = item.Correct
    
    // Build map: LeftItem index → correct RightItem index in original order
    let correctRightText = leftItems.map(left => correct[left])
    let originalCorrectIndices = correctRightText.map(text => rightItems.indexOf(text))
    
    // Fisher-Yates shuffle with derangement check
    let maxAttempts = 1000
    for attempt = 1 to maxAttempts:
        fisherYatesShuffle(rightItems)
        
        // Build map: post-shuffle index of each correct RightItem
        let newCorrectIndices = correctRightText.map(text => rightItems.indexOf(text))
        
        // Check derangement: newIndex[i] != i for all i
        let deranged = newCorrectIndices.every((newIdx, i) => newIdx !== i)
        
        if deranged:
            return { rightItems, newCorrectIndices, attempts: attempt }
    
    // If no derangement found (exceedingly unlikely), return best-guess
    return { rightItems, newCorrectIndices: null, attempts: maxAttempts, warning: "Max attempts reached" }
```

### 4.4 Verification

After shuffle, for each item:

1. **Correct object unchanged:** Deep equality check between original and current `Correct`
2. **LeftItems unchanged:** Deep equality check
3. **RightItems set unchanged:** Same items (via sort + compare), just reordered
4. **Derangement check:** For each i, `rightItems.indexOf(correct[LeftItems[i]]) !== i`
5. **No duplicate RightItems:** Set size equals array length (unless original had duplicates)
6. **All LeftItem keys in Correct exist:** `Object.keys(item.Correct).every(k => leftItems.includes(k))`
7. **All Correct values in RightItems:** `Object.values(item.Correct).every(v => rightItems.includes(v))`

## Appendix A: Derangement Proof

For any set of N distinct items, a derangement exists if N ≥ 2. The Fisher-Yates shuffle produces a random permutation with uniform probability 1/N!. The probability that a random permutation is a derangement approaches 1/e ≈ 36.8% as N grows large.

For N=3: P(derangement) = 2/6 = 33.3%
For N=4: P(derangement) = 9/24 = 37.5%

Expected attempts to find derangement:
- N=3: 3.0 attempts
- N=4: 2.67 attempts

Worst-case probability of failing 1000 attempts:
- N=3: (4/6)^1000 ≈ 10^(-176)
- N=4: (15/24)^1000 ≈ 10^(-176)

**The 1000-attempt retry loop is virtually guaranteed to succeed.**
