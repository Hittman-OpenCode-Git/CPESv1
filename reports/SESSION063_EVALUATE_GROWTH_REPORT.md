## Q3: What financial-reporting topics produce the highest Evaluate conversion rates?

**100% Evaluate conversion** was achieved for:
- Contingencies (ASC 450): 2/2 — highest natural fit for judgment
- Revenue Recognition (ASC 606): 1/1
- Inventory Valuation (ASC 330): 1/1
- Asset Impairment (ASC 360): 1/1
- Deferred Taxes (ASC 740): 1/1
- Disclosure Judgment: 1/1

**0% Evaluate conversion (Analyze only):**
- Fair Value Hierarchy (ASC 820): classification is inherently analytical
- Allowance Method (ASC 326/CECL): estimation is inherently analytical
- LIFO Liquidation: effect analysis is analytical
- Lease Classification (ASC 842): criterion application is analytical
- Consolidation (VIE model): control assessment is analytical
- Cash Equivalents: maturity classification is analytical

**Finding:** Topics where the core question is "should we accrue/disclose/recognize" naturally convert to Evaluate. Topics where the core question is "what category does this fall into" naturally convert to Analyze.
