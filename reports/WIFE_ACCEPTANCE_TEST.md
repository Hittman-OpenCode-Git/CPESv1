# Wife Acceptance Test (WAT) — Test Script

**Version:** 1.0
**Session:** S136 Alpha Freeze
**Tester:** Wife
**Rule:** No developer assistance. If you get stuck, note it — don't ask for help.

---

## Before You Start

Open `index_updated.html` in Chrome, Edge, or Firefox.
Do NOT open any developer tools. Use the app as a normal user would.

---

## Session 1 — First Impressions

### 1.1 Launch
- [ ] Open the app. Does it load within 3 seconds?
- [ ] Is anything obviously broken or confusing?

### 1.2 Take the Beginner Tour
- [ ] You should see a "Take the Guided Tour" button. Click it.
- [ ] Work through all steps. Do the arrows/buttons work?
- [ ] Does each step point to something visible?
- [ ] Does the tour complete cleanly?

### 1.3 Explore the Dashboard
- [ ] Click the Dashboard tab. Does it show anything?
- [ ] Do the numbers and charts make any sense to you?

### 1.4 Start a Practice Session
- [ ] Go to the Study tab.
- [ ] Select "Practice" mode.
- [ ] Pick 1 section (any letter).
- [ ] Set question count to 10.
- [ ] Click Start Session.

### 1.5 Answer Questions
- [ ] Answer all 10 questions. Is the interface clear?
- [ ] After answering, do you see an explanation?
- [ ] Is the explanation helpful?

### 1.6 Bookmark an Item
- [ ] Click the "+ Save" button on any question.
- [ ] Does it show a confirmation?

### 1.7 Close Mid-Session
- [ ] Close the browser tab entirely.
- [ ] Re-open `index_updated.html`.
- [ ] Do you get a "Resume Session" prompt?
- [ ] Click "Resume Session."
- [ ] Are you back where you left off?

### 1.8 Finish the Session
- [ ] Complete the remaining questions.
- [ ] Submit/view results.
- [ ] Do you see your score?

---

## Session 2 — Recovery & May

### 2.1 Recovery Sprint
- [ ] Go to Study tab.
- [ ] Select "Recovery Sprint" mode.
- [ ] Pick 1 section. Start the session.
- [ ] Answer all questions. Any issues?

### 2.2 May Coach
- [ ] Click the Coach tab.
- [ ] Is May visible? Can you read the content?
- [ ] If there are quiz/study options, try clicking one.
- [ ] Does May respond?

### 2.3 Review Session History
- [ ] Click the History tab.
- [ ] Do you see your past sessions?
- [ ] Click into one. Does it show results?

---

## Session 3 — Full Exam

### 3.1 Start Full Exam
- [ ] Go to Study tab.
- [ ] Select "Full Exam" mode.
- [ ] Select all 6 sections (A through F).
- [ ] Click Start Session.

### 3.2 Verify Exam Mode
- [ ] Are the tabs hidden? (You shouldn't see Dashboard/Coach/etc.)
- [ ] Is the hero/header banner hidden?
- [ ] Is the left setup panel hidden?
- [ ] Does the question area take up most of the screen?
- [ ] Is the timer visible?

### 3.3 Answer Several Questions
- [ ] Answer at least 5 MCQs.
- [ ] Are the explanations shown after answering?
- [ ] Can you see study-tool buttons (confidence, "I guessed")? (You shouldn't.)

### 3.4 Case Study (if auto-assigned)
- [ ] If a case study appears, can you read the scenario?
- [ ] Are the exhibits readable?
- [ ] Can you navigate between tasks?
- [ ] Do the tables look like tables (not raw text)?

### 3.5 Pause (if available)
- [ ] Is there a pause button?
- [ ] If yes, pause the exam.
- [ ] Resume. Are you back where you left off?

### 3.6 Close Mid-Exam
- [ ] Close the browser tab.
- [ ] Re-open `index_updated.html`.
- [ ] Resume the exam.
- [ ] Is the timer correct (approximately where you left it)?
- [ ] Are tabs/hidden elements still hidden?

### 3.7 Submit
- [ ] Complete as many questions as you want.
- [ ] Submit/finish.
- [ ] Do you see your score summary?

---

## Session 4 — Stress Test

### 4.1 Unexpected Navigation
- [ ] Try clicking things in an unusual order.
- [ ] Start a session, switch to another tab, come back.
- [ ] Try resuming a session you already completed.
- [ ] Refresh the page mid-question.

### 4.2 May Floating Button
- [ ] During a practice session, is the May floating button visible?
- [ ] Click it. Does May open?
- [ ] Can you ask May a question about the current item?

### 4.3 Settings
- [ ] Go to the Settings tab.
- [ ] Change any setting. Does it persist after a page refresh?

### 4.4 Natural Use
- [ ] Spend 5 minutes using the app however you want.
- [ ] Try to accomplish something realistic (study a topic, test yourself).

---

## End of Test

Thank you! Please fill out the feedback form (WAT_FEEDBACK.md) before you go.
