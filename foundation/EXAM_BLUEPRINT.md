# CMA Part 1 Exam Simulator – Exam Blueprint

**Version:** 1.0
**Status:** Active
**Last Updated:** July 2026

---

# Purpose

This document defines the content organization for the CMA Part 1 Exam Simulator.

Its purpose is to:

* Ensure complete topic coverage.
* Prevent over- or under-representation of subjects.
* Map every question to a learning objective.
* Maintain alignment with the current CMA Part 1 exam blueprint.
* Support future content expansion.

Every question in the simulator shall reference one primary domain and one primary topic from this document.

---

# Difficulty Distribution

Target overall distribution:

| Difficulty     | Target |
| -------------- | -----: |
| Easy           |    15% |
| Moderate       |    45% |
| Difficult      |    30% |
| Very Difficult |    10% |

Questions should primarily assess application and analysis rather than simple recall.

---

# Cognitive Skill Distribution

Target balance:

| Skill         | Target |
| ------------- | -----: |
| Recall        |    20% |
| Understanding |    25% |
| Application   |    35% |
| Analysis      |    20% |

Preference should always be given to application and analysis whenever appropriate.

---

# Question Metadata

Each question should contain, either explicitly or internally, the following metadata:

* Question ID
* Domain
* Primary Topic
* Secondary Topic (optional)
* Difficulty
* Cognitive Skill
* Calculation Required (Yes/No)
* Case Study (Yes/No)
* Estimated Time
* Last Reviewed Date

---

# Coverage Tracking

Maintain a running inventory showing:

* Number of questions by domain
* Number of questions by topic
* Difficulty distribution
* Calculation vs. conceptual ratio
* Case study coverage
* Recently revised questions

This inventory should be regenerated after major revisions.

---

# Quality Standards

Each question should:

* Test one primary concept.
* Have one clearly correct answer.
* Include plausible distractors.
* Use realistic business scenarios.
* Avoid unnecessary complexity.
* Reflect modern management accounting practices.

---

# Gap Analysis

Review the simulator periodically to identify:

* Underrepresented topics
* Overrepresented topics
* Duplicate concepts
* Outdated terminology
* Missing calculation types
* Missing scenario types

Priority should be given to filling content gaps before adding additional questions to already well-covered topics.

---

# Maintenance

Whenever the official CMA Part 1 blueprint changes:

1. Review this document.
2. Update affected domains and topics.
3. Identify impacted questions.
4. Revise question metadata.
5. Rebalance topic coverage where necessary.

This blueprint serves as the master reference for organizing and expanding the simulator.
