# Cost Management

---

## Trap 1

Contribution Margin vs Gross Margin

### Why it Happens

Candidates frequently assume manufacturing costs always belong in Contribution Margin.

### Incorrect Thinking

Contribution Margin includes manufacturing costs.

### Correct Thinking

Contribution Margin excludes ALL fixed costs.

Gross Margin includes fixed manufacturing costs.

### Distractor Pattern

One answer substitutes Gross Margin.

### AI Validation

If fixed manufacturing overhead appears inside Contribution Margin,

flag for review.

---

## Trap 2

Relevant Cost vs Total Cost

### Incorrect Thinking

Use every listed cost.

### Correct Thinking

Only future costs that differ between alternatives are relevant.

### Typical Distractor

Includes sunk costs.

### Validation

Ignore:

* sunk costs
* unavoidable costs

Include:

* opportunity costs
* incremental costs

---

## Trap 3

Allocated Fixed Costs

Allocated costs are rarely relevant.

Do not automatically include them in decision analysis.

# AI-Specific Errors

---

## Trap 35

Matching Instead of Solving

Never select an answer because it "looks familiar."

Always solve independently.

---

## Trap 36

Formula Memorization

Selecting the correct formula

does not prove

the accounting principle was correct.

Validate the governing concept first.

---

## Trap 37

Answer Bias

Do not assume:

A

is more likely than

D.

Ignore answer position completely.

---

## Trap 38

Overconfidence

When multiple reasonable interpretations exist,

report reduced confidence

instead of guessing.

# Distractor Design Principles

Every incorrect answer should represent:

* a realistic accounting mistake
* a common misunderstanding
* an incorrect formula selection
* an arithmetic error
* a unit error
* a conceptual misunderstanding

Never create distractors that are obviously absurd.

---

# AI Validation Checklist

Before approving a question verify:

✓ Correct accounting principle

✓ Correct formula

✓ Correct calculation

✓ Correct interpretation

✓ Correct business conclusion

✓ Correct units

✓ Correct terminology

✓ Correct framework

✓ Correct distractors

✓ No listed trap has been triggered

---

# Final Principle

A correct numerical answer obtained using an incorrect accounting method is still an incorrect answer.

Likewise, a correct accounting method with incorrect arithmetic is also an incorrect answer.

Every approved solution must be correct in **principle, process, calculation, and interpretation**.
